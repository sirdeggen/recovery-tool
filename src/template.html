Derivation scan

This page checks whether a recovery phrase can produce a given BSV address in BSV Browser. It shows only "match" or "no match". It never shows or sends a key.

Before you type your recovery phrase:
  1. Disconnect this computer from the internet.
  2. For the most safety, save this page (File → Save Page As) and open the saved copy offline.
  3. Close this tab when you are done.
The page has no network access: its security policy blocks all connections. Everything runs in this tab.
A mainnet address that starts with 1.
What the scan checks
About 10,500 addresses that the phrase can produce: the BSV Browser address-receive key for each day from 1 July to 31 October 2026, on wallet profiles 0–9; the plain addresses of the wallet identity keys and the master key; and the first 20 addresses of the common BIP44 and BIP32 paths.
